Install Loom
in PixInsight.

Choose the install route for the tools you want. The script repository and native module repository are separate, so add only the one you need.

PixInsight scripts

Loom Preprocess, Frame Selector and Fly-Through are distributed through the signed PixInsight script repository.

  1. In PixInsight, open Resources → Updates → Manage Repositories.
  2. Add the script repository URL above, including the trailing slash.
  3. Choose Resources → Updates → Check for Updates and apply Loom.
  4. Restart PixInsight. Find the scripts under Script → Loom. If they do not appear, use Script → Feature Scripts → Regenerate.

Install from the update repository or a Git checkout, not both. Both copies register the same scripts.

Native Loom modules

Native processes use a separate signed update repository. Add it once to receive compatible modules.

  1. Open Resources → Updates → Manage Repositories.
  2. Add the native module repository URL above.
  3. Choose Resources → Updates → Check for Updates.
  4. Apply the available Loom module update, then restart PixInsight.

PlateSolve preview is available for macOS arm64 and Windows x64.

PixInsight selects a package for your operating system, processor architecture and supported PixInsight version. The module feed is separate from the script repository; the script address remains https://fcarucci.github.io/Loom/updates.xri.

Manual installation

If PixInsight does not offer the module update, download the matching release ZIP, extract it, then choose Process → Modules → Install Modules, select the folder containing the signed module, and restart PixInsight.

Using Siril?

The experimental Siril scripts are installed from the project checkout. On first run, they install their Python requirements into Siril's Python environment.
