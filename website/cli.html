Install the standalone tool

  1. Download the archive matching your computer.
  2. Extract the archive into a folder you want to keep.
  3. Open Terminal on macOS or Linux, or PowerShell on Windows, in that folder.
  4. Run ./loom-solve --help on macOS or Linux, or .\loom-solve.exe --help in PowerShell.

The macOS package is built for Apple silicon with a macOS 14.0 deployment target.

On Windows, install the Microsoft Visual C++ v14 Redistributable (x64) before running the tool.

The Linux builds target glibc 2.35 using an Ubuntu 22.04 build baseline. The ARM64 package targets Jetson Orin through Vulkan; physical-device qualification is pending.

The standalone tool does not use the PixInsight update repository. For the native PixInsight process, follow the PixInsight installation instructions.

Check your download

Compare the archive’s SHA-256 with the checksum next to your download before extracting it.

macOS
shasum -a 256 PATH_TO_ARCHIVE
Linux
sha256sum PATH_TO_ARCHIVE
Windows PowerShell
Get-FileHash PATH_TO_ARCHIVE -Algorithm SHA256

Replace PATH_TO_ARCHIVE with the downloaded file’s path.

Your first solve.

Use a two-dimensional monochrome or three-plane RGB FITS image (primary HDU). No starting coordinate or local star catalogue is required.

macOS and Linux

Print the exact WCS as JSON:

./loom-solve image.fits --json

Save the result next to your image:

./loom-solve image.fits --json --sidecar

Windows PowerShell

Print the exact WCS as JSON:

.\loom-solve.exe image.fits --json

Save the result next to your image:

.\loom-solve.exe image.fits --json --sidecar

Replace image.fits with your image’s path. Sidecar output writes a new image.fits.wcs.json file. Existing files are never overwritten. Results go to standard output; progress and errors go to standard error. JSON preserves the exact WCS, including spline control points; spline solutions require JSON in this preview.

GPU acceleration is enabled by default, with CPU fallback available. Add --no-gpu for CPU-only execution. Optional --gaia PATH files can accelerate catalogue access. First-time online catalogue access may need a network connection; --offline restricts access to embedded, local and cached data.
